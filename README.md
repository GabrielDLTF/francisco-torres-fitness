# Francisco Torres - Nutriólogo Deportivo & Entrenador Personal

Landing Page de altísima conversión diseñada para Francisco Torres (Nutriólogo Deportivo & Entrenador Personal de Alto Rendimiento en Zona Río, Tijuana).

## 🚀 Tecnologías
- **React + Vite + TypeScript**
- **TailwindCSS** (Vanilla CSS Design System & Glassmorphic Utilities)
- **Lucide Icons**

## 🌐 Despliegue en Vercel
Configurado para despliegue continuo en Vercel con rutas SPA `vercel.json`.
